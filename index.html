A PREHISTORIC ARCADE ADVENTURE

고인돌 PREHISTORIK ARCADE

배고픈 원시인 샘(Sam)이 되어 몽둥이로 공룡을 물리치고, 수상한 바위를 두드려 숨겨진 식량을 찾아 고인돌 관문을 돌파하세요!

게임 시작 ↓
SELECT YOUR STAGE
←→ 또는 AD 이동
SPACE / Z / ↑ 점프
X / J / ENTER 몽둥이 내려치기 (바위 타격)
C / K 돌도끼 투척
P 일시정지

원시 시대에서 살아남는 법

01 / ATTACK

찰진 몽둥이 내려치기 & 화면 진동

원시인 샘의 트레이드마크인 거대 참나무 몽둥이! 바닥을 내리칠 때마다 묵직한 타격음과 화면 흔들림(Screen Shake)이 발생하며 공룡들을 단숨에 기절시킵니다.

근접 몽둥이 스매시 원거리 돌도끼 투척
02 / DISCOVER

수상한 바위 타격 & 비밀 식량 폭포

원작에서 허공이나 바위를 두드리면 음식이 쏟아지던 기믹을 재현했습니다! 뼈 문양이 새겨진 고대 바위를 몽둥이로 내려치면 숨겨진 고기와 햄버거가 솟구쳐 오릅니다.

식량 게이지 50% 이상 시 출구 개방 보너스 스코어
03 / LISTEN

AdLib 감성 Web Audio 사운드트랙

외부 음원 파일 없이 순수 Web Audio API 신디사이저로 실시간 합성되는 8비트/FM풍 배경음악(원시림, 화산동굴, 보스전)과 경쾌한 레트로 효과음을 제공합니다.

Web Audio 사운드 CRT 스캔라인 필터

원시 시대 몬스터 도감

초록 공룡 (Raptor)

원시림과 협곡을 순찰하는 가장 흔한 공룡입니다. 몽둥이로 두 번 내려치거나 위에서 밟으면 고기를 떨어뜨립니다.

HP: 2 드랍: 공룡갈비

돌진 멧돼지 (Wild Boar)

날카로운 어금니를 세우고 빠른 속도로 돌진합니다. 점프로 피하거나 타이밍을 맞춰 몽둥이로 제압하세요.

HP: 2 특징: 고속 지상 돌진

보라 익룡 (Pterodactyl)

공중에서 물결 궤적을 그리며 날아다닙니다. 통통 버섯을 밟고 점프해서 치거나 돌도끼(C키)를 던져 격추하세요!

HP: 1 약점: 돌도끼 투척

거대 맘모스 대왕 (BOSS)

스테이지 3 대고인돌 제단을 지키는 보스! 점프 후 착지할 때 양옆으로 충격파 바위를 날리며 체력이 절반 이하가 되면 분노합니다.

HP: 18 패턴: 대지 충격파
